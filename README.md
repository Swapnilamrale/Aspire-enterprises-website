ASPIRE ENTERPRISES WEBSITE
==========================

Files:
- index.html: complete responsive website (HTML + embedded CSS and small JavaScript).

PREVIEW LOCALLY
1. Extract this ZIP file.
2. Open the folder.
3. Double-click index.html to open it in your browser.
4. Internet is required for the optional hero background image.

PUBLISH USING GITHUB PAGES
1. Sign in to https://github.com/ or create an account.
2. Click the + icon (top right) > New repository.
3. Repository name: aspire-enterprises-website
4. Choose Public, then click Create repository.
5. Click Add file > Upload files.
6. Upload index.html (README.md is optional).
7. Click Commit changes.
8. Open repository Settings > Pages.
9. Under Build and deployment, choose Deploy from a branch.
10. Select branch main and folder /(root), then click Save.
11. Wait a few minutes. The Pages section will show the published website URL.

IMPORTANT
- The site is a static website; it does not include an admin panel or database.
- Review the contact details, spelling, product availability and claims before publishing.
- The background image is loaded from Unsplash, so it requires internet access. You can replace the image URL in the CSS if desired.
- GitHub Pages is suitable for a basic company website. A custom domain can be connected later if you own one.
